# Shriram Vidya Mandir Public School — Angular 20

Premium, component-based Angular school website for LKG to Class 5.

## Run
```powershell
npm install
npm start
```
Open http://localhost:4200/

## Important
This version fixes the previous template/compiler issues:
- Real `.html` template files are included for every component.
- Real component `.css` files are included.
- Angular packages are pinned to compatible versions.
- Removed deprecated `@angular/animations` and `@angular/platform-browser-dynamic`.
- Fixed the Events and Principal unmatched closing tags.
- Fixed `gallery` data bindings.
- Fixed boolean `center` inputs on `app-section-title`.
- Removed unused imports that generated NG8113 warnings.
- Added responsive mobile navigation.
- Added gallery lightbox.
- Added scroll-to-top button.
- Added local SVG placeholders so the site works immediately.

Replace the SVG placeholders under `src/assets/school/` with real school photographs when available.
